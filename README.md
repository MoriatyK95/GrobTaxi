# GrobTaxi

A simple mock web-based ride-hailing app built with React and TypeScript.

This initial repository contains the standard Vite starter and development tooling. Ride-hailing screens and features have not been implemented yet.

## Requirements

- Node.js 24 (see `.nvmrc`)
- npm

## Getting started

```bash
npm ci
npm run dev
```

Open the local URL printed by Vite in your browser.

## Commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Start the development server with hot reload. |
| `npm run build` | Check TypeScript and create a production build in `dist/`. |
| `npm run lint` | Run Oxlint. |
| `npm run preview` | Preview the production build locally after building. |

## Stack

- React
- TypeScript
- Vite
- Oxlint
